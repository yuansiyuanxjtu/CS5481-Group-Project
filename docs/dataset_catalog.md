# Five-document dataset catalog

Collection date: 2 November 2026 (Asia/Hong_Kong). Scope: Member A Phase 2.5 pilot only.

## Selection and provenance

Exactly five distinct publicly accessible, official English-language PDFs were selected for banking AI governance, model/data risk, explainability, operational resilience, and responsible adoption. Landing-page titles, dates and direct PDF links were inspected before downloading. Dates below are verified publication/issue dates, not filename-derived estimates. BIS provides the exact publication date in its citation metadata; its cover gives December 2024.

This is a mixed reference corpus: HKMA supervisory documents, non-binding FSB reports, and BIS/FSI policy research. It is not a collection of five binding regulations. The 2019 HKMA circular is retained deliberately for historical comparison and is superseded by the 2026 guidance. The current chunk schema does not carry this version status; downstream users must consult this catalog.

## Download checks and exclusions

All five responses began with `%PDF-`, opened with PyMuPDF without a password, and allowed text extraction on every physical page. SHA-256 checks found zero duplicate files; hashes of concatenated cleaned pages also found zero exact duplicate documents. These checks do not prove absence of overlapping prose or near-duplicates.

The requested MAS FEAT page returned an unavailable-service page through browsing; no MAS PDF was downloaded and no restriction was bypassed. A verified BIS/FSI paper filled the fifth slot. EBA documents were not needed after reaching the five-document cap. Some initial browsing requests failed with cache misses/502; ordinary unauthenticated GET requests to the same official pages succeeded. See `data/catalog/discovery_log.json`.

The unchanged manifest header is `document_id,source_file,source_url`. Its five rows use the direct official PDF URL as `source_url`, preserving a direct citation target. Expanded metadata, checksums, download statuses, and landing pages are in `data/catalog/pilot_sources.json`.

PDFs, chunk JSONL, model weights and the Chroma database remain ignored by Git. They exist locally; this work does not publish or redistribute the complete PDFs.

## Reproduce collection

From the repository root, with the documented Python environment installed:

```bash
.venv/bin/python scripts/download_pilot.py
```

This explicit downloader is limited to the five catalog entries, reuses existing checksum-verified files without network requests, refuses conflicting local files/manifests, rejects non-PDF responses and duplicate checksums, and stops on failures. It performs no crawling or automatic retries. Do not expand the catalog during this pilot. See the quality report for exact offline processing and audit commands.
